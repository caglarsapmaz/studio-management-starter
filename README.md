
# Nova Studio Yönetim Paneli

- Hazırlayan: Çağlar Sapmaz
- Ders: BPR215 İnternet Programcılığı I
- Kullanıcı: Stüdyo yöneticisi

## Salonlar ve dersler

- Performans Salonu: Fitness, Kişisel Antrenman
- Reformer Salonu: Reformer, Pilates
- Denge Salonu: Yoga, Meditasyon

## Projenin Amacı

Bu proje, stüdyo yöneticisinin salonları, üyeleri,
eğitmenleri ve ders programlarını tek bir panel
üzerinden takip etmesini amaçlamaktadır.

Ayrıca üyelik aidatlarının, eğitmen atamalarının
ve eğitmen ücretlerinin yönetilmesini sağlayacaktır.

- npm: 11.9.0
- react: 19.2.9
- react-dom: 19.2.9
- vite: 8.3.6
- @vitejs/plugin-react: 6.3.0
- Dil ve stil: JavaScript, JSX, CSS
- Branch'ler: main, developer

## Yerelde Çalıştırma

1. Repo klasöründe `npm ci` çalıştırın.
2. `npm run dev` komutunu çalıştırın.
3. Terminaldeki Local adresini tarayıcıda açın.
